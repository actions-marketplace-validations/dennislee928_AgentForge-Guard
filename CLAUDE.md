# CLAUDE.md

Instructions for Claude Code in this repository. Keep in sync with `AGENTS.md`; both share the same body.

## Project

AgentForge Guard (`afg`) is a policy-driven code-execution tool for AI coding agents. Plan: `docs/plan.md`. Decisions: `docs/adr/`. Threat model: `docs/threat-model.md`.

## Rules

- Work task by task from `docs/plan.md`. Commit once per finished task (Conventional Commits), and tick its checkbox in the same commit.
- At the end of each phase, re-read `docs/plan.md`, record any deviations in its Alignment log, and commit `docs(plan): align after phase N`.
- Use TDD: write the failing test first. The workspace must build and pass all tests after every commit.
- `afg-core` is the only crate that makes authorization decisions (ADR 0002). Never add policy logic anywhere else.
- **Never weaken, delete or `#[ignore]` a deny, adversarial or isolation test to make a change pass.** Fix the code instead.
- Never use an implicit shell (`sh -c`) in executors. Never inherit the full host environment. Never mount the Docker socket or `$HOME`.
- Never commit real secrets. Test credentials must be obviously fake (e.g. `AKIAFAKEFAKEFAKEFAKE`).
- Docs must not claim that argv matching or prompt instructions are security boundaries.

## Definition of Done (every commit)

```sh
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo deny check
```

Docker isolation tests: `cargo test --workspace -- --ignored` (requires Docker).

## AgentForge Guard

This repository is governed by `agentforge.yaml` (policy `AgentForge Guard`). These instructions are for coding agents; the policy, not this text, is what is enforced.

- Run scripts, generated shell code and anything untrusted through afg: `afg run -- <command>`. afg routes them to an isolated container.
- Check a command first with `afg policy explain -- <command>`. Do not try to work around a denial; ask the user instead.
- Never read or print credential files (`.env`, `.env.*`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `~/.ssh`, `~/.aws`, `~/.kube`).
- Denied: `kubectl delete`, `kubectl drain`, `terraform destroy`, `helm uninstall`, `git push --force`, `git push -f`, `git push --force-with-lease`, `git push --delete`, `docker system prune`, `dropdb`.
- Needs human approval: `npm install`, `npm ci`, `pnpm install`, `pnpm add`, `yarn install`, `yarn add`, `bun install`, `pip install`, `pip3 install`, `cargo install`, `cargo add`, `go install`, `go get`, `kubectl apply`, `kubectl create`, `kubectl replace`, `kubectl patch`, `kubectl edit`, `kubectl scale`, `kubectl rollout`, `kubectl exec`, `terraform apply`, `terraform import`, `terraform state`, `helm install`, `helm upgrade`, `helm rollback`, `docker push`, `git push`, `git reset --hard`, `git clean`, `cargo publish`, `npm publish`, `pnpm publish`, `wrangler deploy`, `go mod download`, `cargo fetch`, `zig build --fetch`.
- Runs in a container: `bash`, `sh`, `zsh`, `python`, `python3`, `node`, `make`.
